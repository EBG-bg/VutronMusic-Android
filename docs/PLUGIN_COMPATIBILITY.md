# 原版插件协议与安卓适配

插件文件沿用 VutronMusic 的 `exports.meta` 和 `exports.<method>` 协议，不要求插件改成安卓专用格式。当前保留的七份原版插件源码、共享类型与结果 Schema 的内容校验见 `packages/plugin-api/UPSTREAM.json`。

## 内置连接与外部插件

七份原版插件随 APK 提供，作为内置音乐库连接直接显示，不再要求安装。新登记的连接默认关闭；升级保留已有开关、账号、实例和插件内歌单。此前未安装或已卸载的内置项只作为关闭的连接出现，不恢复旧账号，也不执行脚本。外部兼容 JavaScript 插件仍通过“导入插件”添加和删除，当前没有联网插件商店。

开关只控制当前实例。开启本身不探测服务器、不执行插件；打开音乐库、登录或读取资料时才按需启动。关闭会停止该实例的 Worker 和待处理调用，本地索引同步也只处理已开启的本地实例。共享 Node 运行时还供音频匹配与 HTTP 兼容使用，不能把关闭插件表述成整个运行时已退出或内存全部归还。

关闭时仍可在本机保存服务器地址，但读取插件账号、登录、扫码、退出及检查必须先明确开启，不会在后台临时运行关闭的插件。下次调用使用保存后的地址，旧服务器的来源上下文不能继续使用。

内置连接的“清除插件数据并关闭”需要确认，重置当前实例的账号、配置及插件内歌单，保留提供项与其它实例。删除外部插件同样需要确认。手机原音频、原生网易云账号、主本地库和共享音频／封面／歌词缓存不因此删除；已有完整缓存可作为独立离线资料播放，不借此联网执行关闭的插件。

宿主登记格式为 format3。旧 `install` 管理调用对内置项幂等且不自动开启；内置 `remove` 明确拒绝，改用 `disable` 或经过确认的 `reset`。外部插件与附加实例仍使用原删除操作。原七份脚本和插件方法协议保持不变。

## 在主界面使用音乐来源

开启额外平台或自建音乐库后，可直接从侧栏选择，也可在首页、音乐库和搜索页切换当前来源。底部导航、播放器、队列与歌曲操作继续共用；无需每次进入管理页再点击“打开音乐库”。当前来源的首页展示其实际支持的推荐内容，音乐库展示其歌单或曲目，搜索只查询当前来源。没有声明的功能会显示对应空状态，不请求其它平台代替。

来源管理页负责开启、关闭、服务器地址及账号配置。来源选择只在本次运行中保留，按来源和账号分别恢复页面位置；账号变更不复用旧账号页面。停用或移除来源后返回主音乐库。默认原版网易云、本地和演示插件不再重复出现在日常来源列表中，仍可从高级兼容区访问已有资料；显式添加的独立实例保留自己的入口和账号。

## 网易云为何也有插件

这七份脚本来自 VutronMusic 原项目的 `src/public/plugin/`，包括它自己的网易云实现，并非网易云官方发布的插件。原版用同一套插件协议接入不同音乐平台和自建服务器；Emby、Jellyfin、Navidrome 在这里是所对接的服务名称。

安卓首页、搜索和主账号卡片沿用已有的原生网易云入口，普通使用无需开启高级兼容入口。插件中的网易云入口用于运行原版插件功能及独立实例，两条路径的账号资料分别保存，开启兼容入口不会自动复制或替换原生账号。插件默认 API 由应用内置服务承接，无需另搭网易云 API 服务器。

原版网易云和本地插件放在高级兼容区，演示模板放在开发区。它们保持原功能和已有资料；日常界面只显示一组原生网易云与本机音乐入口，额外来源与之并列。

## 播放音源与歌词／评论顺序

网易云原生入口与已验证的原版网易云插件实例共用取址规则：先匹配已授权的本机文件、使用本曲目的独立完整缓存，再请求官方完整音频；官方不可用且允许匹配其它音源时才进入原有兜底，按歌曲匹配证据和可用音质选择。原生入口用原生账号，兼容实例用自己的会话；匿名实例仍可访问允许的免费内容，不借用主账号。

本地匹配只读取已有索引，不联网或重扫；匹配文件与 CUE 信息不会覆盖插件的队列、缓存、账号和音量身份。其它平台和自建音乐库保留各自音频来源。

设置的播放策略卡展示实际兜底候选与当前播放音源。候选由运行时和界面共用的 `source-policy.json` 提供，列表不是逐个固定播放顺序。音乐库连接开关管理账号、歌单及插件功能，音频匹配候选由播放策略卡的独立开关控制；歌词和评论优先级只控制对应资料读取，不充当音频排序。

| 本地音乐 | local | 60 | 本地库、歌单、喜欢、搜索、歌词、专辑与艺人、播放记录 |
| 网易云 | library | 61 | 二维码／Cookie 登录、推荐、搜索、歌单写操作、专辑／艺人、FM、云盘、MV、四类资源评论与楼层 |
| 酷狗 | library | 60 | 二维码登录、推荐／分类、搜索、歌单、专辑／艺人、歌词、FM、云盘、MV、读取评论及楼层 |
| Emby | stream | 33 | 账号登录、自建音乐库、搜索、歌单、喜欢、专辑／艺人、歌词和播放上报 |
| Jellyfin | stream | 33 | 账号登录、自建音乐库、搜索、歌单、喜欢、专辑／艺人、歌词和播放上报 |
| Navidrome | stream | 32 | 原生登录、Subsonic 音频／封面／歌词、搜索、歌单、专辑／艺人、喜欢和播放上报 |

方法存在不表示服务端一定支持写入；例如酷狗声明评论只读，不能因为有占位方法就显示发表评论。内置索引的 `unsupportedMethods` 由源码 AST 识别整个函数无条件返回 `code: 404` 的占位实现，保留原导出列表，不执行方法探测网络，也不把正常方法的条件失败分支当成不支持。界面同时根据实例状态、实际导出、此占位清单和 `meta.capabilities` 决定入口。

原版酷狗的 `baseUrl` 默认为空，需要配置兼容的酷狗 API 服务。三个自建音乐库需要填写用户自己的服务器。原版网易云指向桌面内置 API；安卓宿主应在应用内适配该虚拟地址，不把桌面端口暴露给外部网络，也不要求用户另行部署网易云 API。

## 宿主接口

- 每个实例独立保存 `api.store` 和 `api.db.PluginData`；复制同一插件创建实例时，账号资料不能互相串用。
- `api.http.get/post/delete` 的参数、请求头及 `raw` 语义保持一致。`raw=true` 返回 `{data,status,headers}`，否则只返回响应体。
- 本地 `Track`、`Album`、`Artist`、`Playlist` 和 `PlaylistEntry` 的形状及增删、计数、排序语义需要由安卓库适配。`api.db.get('Track')` 返回 `{songs:[...]}`，不能一律当作数组。
- 原版 `sourceContext` 由插件拥有，宿主只保存、校验为 JSON 并透传，不能根据网易云字段猜测其他插件身份。
- `api.utils` 保留歌词解析、MD5、盐与加盐令牌、受授权本地歌词读取及文件存在检查。权限不能扩大到用户未授权的手机文件。
- 查看插件列表不执行插件代码；实例启停、移除及请求超时必须清理其 Worker 与待处理请求。仅本地模式禁止网络能力。

## 播放与时间单位

`songUrl` 的参数直接来自曲目的 `sourceContext`；结果为 `{code,data:{url:string[],replayGain,peak,cueOffset?,cueDuration?}}`。`cueOffset`、`cueDuration` 使用毫秒。

Emby 和 Jellyfin 的 `songUrl` 返回原版 `vutron://get-plugin-asset` 地址，宿主必须在同一插件实例执行 `getStream` 并保留其返回的认证请求头；不能只把虚拟地址交给 Android MediaPlayer。Navidrome 直接返回带认证参数的 HTTP(S) 地址。本地的 `vutron://local-asset` 需要解析到已授权的 Android 音频。

插件歌词行 `start/end` 使用秒，逐字 `lyric.info[].start/end` 使用毫秒；这与桌面 `sharedCoreLyrics` 适配一致。转换到安卓歌词时必须分别转换，译文、真实逐字与 CUE 时间不能混用单位。

## 跨来源关联

`PluginSourceRegistry` 持久保存显式确认或自动匹配的 `TrackSource` 关系，以插件实例、当前账号作用域和公开 `Track.id` 区分来源，原始 `sourceContext` 整体保存。没有公开曲目 ID 的查找只比较完整 JSON 结构，不读取或猜测上下文中的 `id`、`hash` 等字段；账号或服务器变化后，旧作用域不能成为自动候选。

`PluginSourceMatching` 沿用桌面策略：仅给非 `library` 曲目匹配启用且支持 `matchTrack` 的 `library` 插件；已有关联跳过请求。官方匹配标记为已确认，搜索置信度至少 80 标记已确认、50–79 保留为较低优先级候选，低于 50 忽略。前后检查来源双方的账号，失败保留已有关系；没有公开 ID 时使用插件的 `getTrackDetail` 补全，不解析上下文代替公开 ID。

歌词和评论候选先按确认标记降序，再按用户来源优先级稳定排序。`self` 指当前来源；与桌面一致，`library` 来源的歌词调用只忽略 `self` 的排序位置，自身仍保留为回退候选。评论确定实际返回数据的来源后，分页、楼层及写操作继续使用该来源的上下文，不能把来源 A 的评论 ID 交给来源 B。完整为空时继续尝试其他候选。

优先级通过 `priorities`／`setPriorities` 导出和恢复。账号资料与来源上下文留在应用私有目录，不随设置备份导出。

本地插件各实例的收藏和自建歌单通过 `PluginLocalBackup` 转成现有可恢复歌单资料，保留曲目次序、简介、CUE 片段、单曲音量和歌词延迟。恢复后显示在恢复歌单中，重新授权音频目录时按已有元数据指纹关联文件；不会导出授权、绝对路径、插件账号或 `sourceContext`。如果旧索引已丢失某条目的曲目资料，会明确报错并保留原始状态，避免生成静默缺曲的备份。

## 校验与依赖

Android 内嵌的 Node 18.20.4 不带 ICU。构建阶段使用锁定的 `regexpu-core` 6.5.4 和 Unicode 18.0.0 完整属性数据，将实际 JavaScript 正则字面量、可静态求值的 `RegExp` 构造器中的 Unicode 属性及 `v` 集合语法展开为等价范围／序列；不是 ASCII 或部分语言的退化匹配。原插件及共享上游 TypeScript 源文保持原样。转换只应用到生成的运行库文件，`runtime-compat-contracts.json` 和 `runtime-compat-dependencies.json` 记录输入／输出 SHA-256、表达式位置、标志和数据版本。`node scripts/runtime-regex-compat.cjs --check` 检查整个运行库是否仍存在未转换的实际表达式，并核对产物哈希；构建工具及生成数据的许可随应用法律材料保留。

七份原版插件和 APK 内依赖均经过这套构建检查，需适配的依赖正则在构建时转换。第三方 JavaScript 插件的动态导入及宿主 API 已实现；运行时新导入的源码不经过 PC 构建转换，仍受内嵌 Node 18.20.4 的语法和无 ICU 边界约束。第三方脚本若自行使用 Unicode 属性正则（`\p`／`\P`）或 `v` 集合语法，需要先生成兼容写法再导入。原版插件协议兼容不代表任意桌面 JavaScript 语法或 ICU 功能完全相同。

成功结果按原版 `PluginResultSchema` 校验。保留桌面按方法的失败默认值；对原版现有的布尔 `systemPing`／`doLogin`、空账号字段做限定兼容，不放宽其他成功结果。`getStream`、`getPic` 和 `intelligencePlaylist` 属于原版已使用的扩展，单独建立结果约束。

共享契约源码仍与上游逐字节一致。上游锁使用 Zod 4.3.6；安卓运行依赖单独锁定为安全修复版本 4.6.6，使用其 CommonJS 实现，并保留 MIT 许可。该版本提前执行有界集合的长度检查；外部输入的大小和运行资源限制仍由宿主负责，不能把依赖升级等同于取消输入边界。应用内网易云 API 固定为原锁中的 `@neteasecloudmusicapienhanced/api` 4.36.1，其依赖隔离在该包内部，既有备用音源引擎 0.28.0 保持不变。`basic-ftp` 以限定覆盖修复 FTP 目录解析的正则拒绝服务问题；不提升网易云 API 的主版本。开发锁、可重现生成脚本及许可正文一并保留。

自动化合成服务检查用于证明参数、分页、认证隔离与返回形状；不等同于真实账号、平台策略、会员授权或所有第三方服务器版本已经验收。
