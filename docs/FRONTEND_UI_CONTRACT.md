# 前端界面与交互规范

适用于安卓页面和应用内控件的修改。先定位受影响的共享组件、同类入口和页面状态，再实现与验证；完成条件同时包含信息层级、动效、焦点、返回和错误恢复。

## 现有基础与缺口

主题来源是 `apps/android-vutron/src/platform/appearance.ts` 和上游主题资源；`src/style.css` 已提供颜色、表面、阴影及动效变量。选项、滑条、折叠卡片、图标和弹层已有共享实现，应先复用。圆角、间距、字级和阴影层级仍有分散定义，需要随相关控件的修改集中整理，避免再增加同类局部覆盖。

截至 2026-11-02，已有浏览器焦点、返回、手势、拖动、字号及横竖屏检查，但截图分散保存在各检查中，没有统一的已确认视觉基线与自动差异比较。`.github/workflows/mobile.yml` 执行单元检查和构建，尚未执行浏览器交互与截图比较。以下规范不是所有页面已经验收的声明。

## 优先检查的页面与状态

先按以下九组处理高频页面；检查本次受影响的组及共用入口，不为无关页面重复完整测试。

| 页面或入口 | 需要区分的状态与关键行为 |
| --- | --- |
| 登录与账号 | 二维码加载、等待、过期、失败、登录恢复、会话失效、仅本地入口；错误可恢复，登录失败不丢本机资料 |
| 首页 | 首次加载、有旧资料时刷新、空推荐、请求失败、离线；刷新按钮必须更新所指内容 |
| 搜索 | 未提交、搜索中、有结果、空结果、失败、分页；输入草稿与已提交查询分开，旧响应不覆盖新查询 |
| 在线歌单库 | 空库、加载、失败、自有与订阅、列表与卡片、排序与自定义拖动；工具栏不因长文案留下大块空白 |
| 本机音乐与缓存 | 无目录、授权失效、扫描中、取消、失败、空库、缓存歌单与音频；来源清晰，移除范围明确，保留原文件 |
| 歌单与实体详情 | 在线、本机、缓存；自有与只读；空列表、加载、失败、分页、歌曲菜单；权限和操作结果一致 |
| 正在播放与歌词 | 无歌曲、获取地址、播放、暂停、失败、无封面、无歌词、真实或估算逐字；封面切换、seek、倍速及横屏不互相遮挡 |
| 设置与关于 | 登录或仅本地、折叠或展开、读写中、保存失败、更新状态、法律正文；账号优先，迷你播放条按页面规则隐藏 |
| 侧栏与弹层 | 侧栏、歌曲菜单、队列、评论、倍速、选择及确认；空内容、滚动、嵌套、下拉取消、键盘、系统返回及焦点恢复 |

空、加载、错误、离线、会话失效和仅本地只检查适用状态。自动断网与手动离线是不同状态；恢复网络不能擅自取消用户手动选择。缓存可读与账号有效也不能混为一谈。入口使用 `hasAccess`、`onlineAvailable`、`loginVisible` 等对应能力判断，避免仅凭 `loggedIn` 隐藏仍可用的本机功能。

## 视觉与控件约束

- 颜色复用主题和 `--ink`、`--muted`、`--accent`、`--surface`、`--line` 等变量；重复的尺寸、圆角、间距、阴影和字级优先整理到共享样式或组件。检查最终计算样式，避免靠后追加 CSS 掩盖前面的冲突。
- 标题、正文、辅助说明和操作标签保持清晰层级，跟随界面字号；歌词正文保留独立字号。150% 时允许合理换行，不以缩小文字掩盖溢出。
- 图标沿用 `OriginalIcon` 的 mask 和 20/24 px 体系，参见 [移动端图标](ICONS.md)。新增或替换的图标须验证实际加载与绘制，路径存在或 CSS 引用成功不足以证明可见。
- 新文案补齐简中、繁中、英文；长标题和英文按钮要参与布局检查。新增持久偏好接入备份恢复，并明确全局或按账号保存，账号切换不得串数据。

| 控件与现有实现 | 必须保持的行为 |
| --- | --- |
| 按钮与开关，公共按钮样式 | 悬浮、按压、键盘焦点、选中与禁用均有明确反馈；亮起与退暗有过渡；触摸可直接操作，不依赖 hover，也不误触发文字框选 |
| 选项，`AppSelect.vue` | 使用应用主题；键盘选择、取消、焦点循环、背景隔离及滚动锁定；关闭恢复位置与焦点。应用内不使用原生 `select`、系统选项框或默认颜色面板；文件、权限、安装等系统流程保留 |
| 数值滑条，`ThumbRange.vue`、歌词延迟控件 | 仅滑块头部起拖，捕获后可移出头部继续；即时反馈，提交时机明确；保留键盘和数值输入，端点不裁切、不重叠，空白轨道可滚动页面 |
| 定时滚轮，`ArcWheel.vue` | 整块调整区可起拖，输入框保留编辑；连续反馈、松手吸附、秒数进借位及上下限一致；键盘和数值输入可替代拖动 |
| 设置卡片，`CollapsibleSettingsCard.vue` | 按内容高度展开与收起，支持连续开合；焦点和滚动位置合理，结束或取消后无残留高度及动画循环 |
| 歌单拖动，`PlaylistLibrary.vue`、`playlistOrdering.ts` | 抓起预览、条目让位、边缘滚动；松手保存，取消恢复原顺序；筛选不修改底层顺序，点击仍可进入，长按菜单与拖动互不抢占 |
| 弹层，`modalFocus.ts`、`sheetDrag.ts` | 顶层接收焦点与返回，背景隔离且不滚动；下拉与短拉回弹一致，滚动内容、滑条和输入优先。关闭并释放焦点陷阱后再恢复触发点，手势结束不误点下方操作 |
| 错误提示，`AppErrorNotice.vue` 等 | 显示可理解的原因与有效恢复入口，保留诊断；读取失败可重新加载，写入失败保留原状态，不能把重试绑定成重复创建或删除 |

普通颜色输入可作为自定义调色器的内部实现，但不能让应用内入口弹出风格不同的系统调色面板。

## 动效检查

动效读取 `style.css` 的 `--motion-*` 和 `platform/motion.ts`。按钮反馈、设置折叠、侧栏、弹层、页面转场按用途分别取时长，避免全部套用一个速度。手指拖动时即时跟随，松手后的吸附、回弹及退场再使用缓动。

CSS、Vue Transition、Web Animations 和 requestAnimationFrame 都遵守三种偏好：

- 完整动效：即使系统减少动效，也保留应用完整动效。
- 跟随系统：响应系统偏好的实时变化。
- 减少动效：取消装饰性运动，保留状态辨识和直接拖动反馈。

同时检查开始、中途取消、快速反向操作及结束后的清理。后台或卸载停止无效循环；正常关闭先完成退场再清理。静态截图只能证明布局和最终状态，不能证明时长、连续性或触摸跟手。

## 固定视觉场景

以下为待统一接入的固定场景，尺寸均为 CSS px，不是设备物理分辨率。共享控件或公共样式变更覆盖整组；局部修改选择受影响场景，至少覆盖基准与窄屏大字，并补上具体故障组合。沿用仍有效的检查结果。

| 场景 | 视口 | 主题 | 界面字号 | 语言 |
| --- | --- | --- | --- | --- |
| 基准 | 360 × 800 | 浅色 | 100% | 简中 |
| 常用深色 | 390 × 844 | 深色 | 100% | 简中 |
| 窄屏长文案 | 320 × 720 | 浅色 | 150% | 英文 |
| 深色大字 | 360 × 800 | 深色 | 150% | 繁中 |
| 窄屏常规 | 320 × 720 | 深色 | 100% | 简中 |
| 常用大字 | 390 × 844 | 浅色 | 150% | 简中 |
| 横屏大字 | 1024 × 768 | 浅色 | 150% | 英文 |
| 横屏深色 | 1280 × 800 | 深色 | 100% | 繁中 |

基准使用完整动效；另在同一受影响页面验证减少动效，以及跟随系统在两种系统偏好间切换。迷你播放条的显示与隐藏、空与长列表、嵌套弹层按页面适用性补充，不机械展开所有状态的笛卡尔积。

截图使用固定合成账号、曲目、长文案、封面和时钟，隔离真实会话与网络波动；等待字体、图片、数据和布局稳定，在确定滚动位置截取。记录浏览器版本与渲染环境，使用同一环境比较。不能为了截图稳定而关闭正在验证的动效。

先确认每个场景的正确截图，再建立基线与差异比较；变化须能对应到本次预期，不能直接批量接受新图。合成基线可作为测试夹具，运行截图与差异图放 `_analysis/`，不包含真实用户资料。截图生成、人工查看和自动基线比较须分别说明。

现有 `tests/browser-personal-ui.cjs`、`browser-app-select.cjs`、`browser-landscape.cjs`、`browser-timer-wheel.cjs`、`browser-sheet-gestures.cjs` 及 `browser-features.cjs` 可复用交互和合成数据。后续仍需统一场景入口、确认基线并接入 CI，完成前不能宣称已具备自动视觉回归。

## 每次修改的完成条件

| 维度 | 检查内容 |
| --- | --- |
| 信息层级 | 主操作易发现，来源与当前状态清晰；字号、图标、换行、层级和安全区正确，无重叠、裁切或异常留白 |
| 动效 | 开合、切换、拖动与取消连续；三种偏好生效，无滞留遮罩、样式或后台循环 |
| 焦点 | 触摸与键盘均可操作；弹层焦点不泄漏，嵌套关闭顺序正确，关闭后回到有效触发点 |
| 返回 | Android 返回、Escape、关闭按钮及手势按当前层级处理；先退出顶层交互，再返回页面，保留应保留的滚动与选择 |
| 错误恢复 | 空、失败、离线和权限失效有对应操作；失败不丢原资料，取消不提交，旧响应不覆盖新状态 |

修共享问题时查齐同类入口，并用能复现原问题的最小交互检查验证；不写只比对源码字符串就声称视觉通过的测试。构建成功、单元检查、浏览器交互、视觉比较和 Android 运行各自只证明其覆盖范围。尚未检查的页面或组合明确保留，不用测试数量替代完成判断。
